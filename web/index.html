Tài liệu cần đối chiếu

Các file Excel phải có định dạng .xlsx.

Danh sách hồ sơ nhà thầuiCác file Excel nhà thầu nộp — mỗi file là một nhà thầu, chọn được nhiều file cùng lúc.

Tên nhà thầu được đoán từ tên file; bấm vào tên để sửa nếu sai.

Bắt buộc
Chọn 1 file: kiểm tra hạng mục, mã, đơn vị, khối lượng và yêu cầu trong phụ lục. Chọn từ 2 file: hệ thống bổ sung so sánh giá giữa các nhà thầu.
Thiết lập mức cảnh báo

Giữ nguyên giá trị mặc định nếu bạn chưa có quy định riêng.

PDF hoặc ảnh scaniNhận PDF, PNG, JPG, TIFF, WEBP, BMP. Chọn được nhiều tài liệu.

Mỗi tài liệu xuất ra một file Excel riêng.

Có thể chọn nhiều tài liệu. Mỗi tài liệu sẽ được xuất thành một file Excel riêng.

Bắt buộc
Chưa có tài liệu scan nào được chọn.

Cách nhận dạng

Chọn theo độ rõ và cấu trúc của tài liệu.

Hai file phải là chào giá của CÙNG một nhà thầu. Hệ thống báo cáo hạng mục thay đổi giá/khối lượng/thương hiệu, thêm mới, đã xoá và mức tăng giảm tổng thành tiền.
Hệ thống ghép từng yêu cầu ở cột "Ý kiến CĐT" với dòng tương ứng trong file phản hồi và báo trạng thái ĐÃ TRẢ LỜI / CHƯA TRẢ LỜI / KHÔNG THẤY TRONG PHẢN HỒI.

Hồ sơ mời thầu — HSMTiTải lên HSMT để hệ thống đọc xem gói thầu yêu cầu những tài liệu gì, rồi dựng checklist đúng theo đó.

Nhận .zip, .pdf, .docx, .xlsx.

File .doc đời cũ cần lưu lại thành .docx hoặc .pdf.

Tuỳ chọn — tải trước để hệ thống biết gói thầu yêu cầu những gì. Có HSMT thì checklist dựng theo đúng yêu cầu của gói thầu; bỏ trống thì dùng bộ 12 đầu mục mặc định.

Không bắt buộc
Chưa chọn HSMT — sẽ dùng checklist mặc định 12 đầu mục: đơn chào giá, BOQ, danh mục vật tư, BCTC 3 năm, năng lực pháp lý, hợp đồng tương tự, nhân sự, tiến độ, BPTC, ATLĐ, catalogue, ủy quyền.

Hồ sơ nhà thầu (file ZIP)iBấm phải vào thư mục hồ sơ mỗi nhà thầu → Nén thành file ZIP. Mỗi nhà thầu một ZIP riêng.

Đặt tên ZIP theo tên nhà thầu để hệ thống nhận đúng.

Nén toàn bộ thư mục hồ sơ của mỗi nhà thầu thành một file .zip rồi tải lên. Có thể chọn nhiều nhà thầu.

Bắt buộc
Chưa có hồ sơ nào được chọn.
Hệ thống tự đọc tên nhà thầu từ tên file ZIP (bấm vào để sửa nếu cần), quét tên file/thư mục bên trong và chấm ĐẠT/THIẾU theo checklist ở trên.
